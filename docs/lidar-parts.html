Optional: phone-free version

Add a buzzer and the scanner plays the tone itself, so it works with an iPhone or no phone at all. The firmware already supports it. Wire the buzzer's S pin to GPIO 25, + to 3V3, and − to GND.

  • $2–6
    Searchpassive piezo buzzer module 3 pin
    • Check: it says passive (an active buzzer only plays one note) and comes as a module with pins, so it plugs in without soldering.

This is the buzzer version. Seven wires, all push-on jumpers. Find each pin by the name printed beside it on the board. Pin positions vary between sellers, and the board is mounted upside down, so don't go by position.

Before plugging in power

Check which wire is which on the sensor's cable, using the labels on the sensor or the seller's diagram. Don't rely on wire colors. Power on the wrong pin can damage the sensor. The pin numbers above come from a vendor's notes, not Benewake's official datasheet. Also check that the buzzer module is passive and marked S, + and −. Some are labelled I/O, VCC and GND instead.

When the parts arrive

  1. Install the free Arduino IDE on the Mac, then add ESP32 support: Boards Manager → esp32 by Espressif.
  2. Open firmware/lidar-ble/lidar-ble.ino from the FlyingBlind repo, plug in the board, pick it under Tools → Board, and click Upload.
  3. If the Mac doesn't see the board, it may need a USB driver named on the small chip near the USB socket (usually CH340 or CP2102).
  4. Wire the sensor as above, power it up, then open the app on the Pixel and choose ESP32 LiDAR as the source, with Feedback set to Tone.
