Software design overview

Two programs work together. The firmware runs on the scanner itself and turns distance into a tone on its own buzzer, so no phone is needed. The phone app is optional: it can speak distances, play the tone through the phone, and work with other laser meters.

Where a reading goes

The buzzer path works on its own, which is why the scanner also works for iPhone users: Safari can't talk to Bluetooth devices from a web page, but the scanner doesn't need it to.

The firmware, on the scanner

A small Arduino program for the ESP32. It has no settings screen: the behaviour is fixed in the code, with a few values near the top to change by hand.

Reading the sensor

The sensor sends a 9-byte frame 100 times a second. The firmware checks the header and checksum, and treats a weak return (signal strength under 100) as "no target" rather than trusting the distance.

Distance to pitch

Closer is higher, like a parking sensor. The scale is logarithmic: each doubling of distance moves the pitch by the same musical step, so there's fine detail up close. 0.2 m plays 3000 Hz and 5 m or more plays 400 Hz.

Smooth, but honest

Each reading closes half the gap to the new pitch, so waving gives a smooth sweep, yet a jump from a near object to a far wall is still a clear step. It settles in about 30 ms.

Bluetooth

Advertises as FBLidar and sends a 4-byte reading 50 times a second: distance in millimetres (0 = no target) and signal strength.

What each sound means

The sounds are designed so the user never has to guess whether silence means "nothing there" or "something's broken".

  • Three rising beepsSwitched on and running.
  • A steady toneSomething is in front. Higher means closer.
  • SilenceNothing in range, or a surface the sensor can't see well (glass, a black surface far away). A single dropped reading doesn't cut the tone; silence needs 60 ms of "no target".
  • A low tick every 3 secondsThe sensor has stopped sending. Check its wires. This starts 2 seconds after the last reading, so a fault is never mistaken for an empty room.

The phone app

A web app that installs to the home screen and works offline. It runs in Chrome on Android, which can talk to Bluetooth devices from a web page.

Sources

Every source (the ESP32 scanner, a Leica DISTO, a Bosch GLM, a simulator, a Bluetooth explorer) is a small driver that reports readings the same way, so the rest of the app doesn't care where a reading came from.

Speech mode

Speaks each measurement in metres, feet and inches, or inches. A fast stream from the scanner isn't spoken, since it would talk over itself; press Measure to hear the latest distance.

Tone mode

Plays the tone through the phone, with the same closer-is-higher rule. It fades out if readings stop for 1.5 seconds, so silence never hides a stale distance.

Built for a screen reader

The reading's label doesn't change many times a second in tone mode, so TalkBack isn't flooded. The screen stays awake while scanning.

The simulator lets the app be tried without hardware: it pretends to be in a room, and on a phone, turning the phone left and right aims the pretend sensor.

Not yet tried on real hardware

The firmware and the scanner's Bluetooth driver were written from the sensor's datasheet and haven't run on a real board yet, so expect some debugging the first time. The Leica and Bosch drivers follow community notes and haven't been checked against real meters.
